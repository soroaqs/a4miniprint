# a4miniprint

a4miniprint 是一个极简 Android 图片打印工具。它支持两种顶层模式：把手机照片按近似 4×6 的比例排版到 A4 纸上，以及把横向多栏图片拆成多张 A4 竖版页面。应用通过 Android 系统打印服务输出，适合在打印机只提供 A4 纸张选项时使用。

## 功能

- 从系统照片选择器选择一张或多张照片。
- 从系统分享面板直接分享图片到 a4miniprint。
- `4×6 照片` 模式：默认在一张 A4 纸上排列 4 张近似 4×6 照片，支持「每页一张」。
- `分栏拆印` 模式：把一张横向多栏图片按 2、3 或 4 栏拆成多张 A4 竖版页面。
- 分栏拆印提供应用内切分线预览，滑杆调整时红线实时移动。
- 4×6 模式支持完整显示照片，或裁切边缘以填满 4×6 区域。
- 分栏拆印支持等比适配或拉伸填满 A4，并提供独立切分线滑杆。
- 默认按 300DPI 打印优化输出；也可切换为原始分辨率。
- 自动处理 JPG 常见的方向信息，横版照片会旋转到竖版格子。
- 支持常见 JPG、PNG 等系统可解码图片。
- 无广告、无账号、无联网功能。

## 适用环境

- Android 12 / API 31 及以上。
- 已在鸿蒙 4.2 的 Android 兼容层上完成基本安装和 Save as PDF 验证。
- 打印输出依赖 Android 系统打印服务；打印机需能在系统打印列表中被选择。
- 默认纸张规格为 A4。请在系统打印预览中保持 A4，否则输出效果可能变化。

## 安装

1. 下载 Release 页面中的 APK。
2. 在手机上允许对应文件管理器安装未知来源应用。
3. 点击 APK 并完成安装。
4. 图标和应用名称均显示为 `a4miniprint`。

如果 Release 附带 SHA-256 校验文件，可在电脑上执行以下命令确认 APK 未损坏或被替换：

```bash
shasum -a 256 a4-mini-print-v1.0.8.apk
```

首次安装不需要打开开发者选项。只有需要通过 USB 使用 `adb install` 排查安装问题时，才需要开启开发者选项和 USB 调试。

## 使用方法

### 方式一：应用内选择照片

1. 打开 a4miniprint。
2. 点击「选择照片」。
3. 选择一张或多张图片。
4. 选择 `4×6 照片` 或 `分栏拆印`。
5. 选择对应的排版、填充、栏数、切分线和输出精度。
6. 点击「开始打印」。
7. 在系统打印预览中确认纸张、份数和色彩等参数。

如果选择 `分栏拆印`，第一版只支持一张图片。应用会按从左到右的顺序生成多张 A4 竖版页面。

### 方式二：从图库分享

1. 在图库中选择一张或多张图片。
2. 点击分享，选择 a4miniprint。
3. 应用会直接进入主界面，并载入分享的图片。
4. 按需要选择功能模式、排版、栏数、切分线和填充方式；分栏模式下可直接查看切分线预览。
5. 点击「开始打印」，并在系统打印预览中确认打印。

每次载入新图片时，功能模式都会默认回到 `4×6 照片`。

## 打印选项

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| 功能模式 | 4×6 照片 | 选择照片排版或分栏拆印 |
| 排版模式 | A4 四宫格 | 一张 A4 输出 4 张近似 4×6 照片；超过 4 张自动分页 |
| 填充方式 | 完整显示 | 不裁切图片；比例不是 2:3 时会在格子内留白 |
| 栏数 | 3 栏 | 分栏拆印支持 2、3、4 栏 |
| 切分线 | 等分 | 每条切分线可独立微调，最小步进为 0.1% |
| 分栏预览 | 自动显示 | 仅在分栏拆印模式显示，用于确认切分线位置 |
| 分栏填充 | 等比适配 | 按高度优先适配 A4，不裁切；也可选择拉伸填满 A4 |
| 输出精度 | 300DPI 打印优化 | 输出体积更小，适合实际打印 |
| 纸张规格 | A4 | 请在系统打印预览中保持 A4 |

如果选择「填满 4×6」，应用会居中裁切照片边缘，让照片填满 2:3 的格子。这符合常见照片冲印逻辑，但会丢失部分边缘内容。

如果选择「原始分辨率」，PDF 手动放大查看会更清晰，但生成时间、内存占用和输出体积都会增加。

`分栏拆印` 默认使用「等比适配」，按高度优先适配 A4 竖版。三栏图拆分后每栏较窄，因此左右留白会比较大，这是保持比例不变形的正常结果。若选择「拉伸填满 A4」，图片会横向拉伸，可能造成文字变形。

## 隐私与安全

a4miniprint 只在本地处理照片：

- 不申请网络权限。
- 不申请读取相册存储权限。
- 不上传照片。
- 不包含广告、账号或第三方分析 SDK。
- 不主动在应用目录生成图片、PDF 或缓存文件。

应用使用 Android 系统打印服务完成输出。系统打印服务自身的临时打印数据由系统管理，不属于应用主动保存的文件。

## 常见问题

### 安装时提示解析包错误

- 重新下载 APK，确认文件未被压缩成 ZIP 或重命名。
- 确认设备为 Android 12 / API 31 及以上。
- 允许当前文件管理器安装未知来源应用。
- 如仍失败，可使用 `adb install -r <apk路径>` 查看系统返回的具体错误。

### 打印预览出现空白

这是部分填充方式的正常结果：

- 「完整显示」不会裁切照片，比例不匹配时会留白。
- 「填满 4×6」会消除格子内留白，但会裁掉部分照片边缘。

### 分栏拆印的切分线不准

应用第一版不自动识别栏边界。请在「切分线」滑杆中分别微调每条竖线，使它落在图片的栏间空白处。
分栏预览使用降采样后的图片，仅用于观察切分线位置；最终输出仍按打印设置的分辨率重新解码，预览不参与打印输出。

### 照片方向不对

请先确认系统图库中的显示方向是否正确。如果图库中方向正确但打印预览错误，请记录照片格式和来源，并反馈到 Issue。

### 真实打印仍有偏移

Save as PDF 已验证应用排版坐标正常。如果喷墨打印仍整体偏移，可能是打印机物理不可打印边距或系统打印缩放造成。请反馈打印机型号、纸张设置和实际偏移方向。
